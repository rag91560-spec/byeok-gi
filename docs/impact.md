## Product Scope

Varo targets a niche but high-maintenance problem: game localization workflows where each engine format needs separate scan, extraction, translation, apply, rollback, and regression behavior.

Current maintained areas include:

- game engine scanning
- local translation memory/library database
- offline baseline translation
- optional provider-backed AI translation
- apply/rollback workflows
- Electron packaging and updates
- manga OCR workflow
- subtitle workflow
- Discord support operations
