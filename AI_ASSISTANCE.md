# AI Assistance

Varo is maintained by a human project owner with assistance from AI coding tools.

AI assistants, including Claude and OpenAI Codex, may be used for implementation support, code review, refactoring, test maintenance, documentation cleanup, and release workflow checks. The maintainer remains responsible for reviewing, accepting, and shipping all changes.

AI assistance does not change the license, copyright ownership, user responsibility model, or rights-holder takedown process described in this repository.
