# 📝 아카라이브/코네 게시물 양식 (Varo 사용 후기)

> 디버깅용 게임 공유 시 이 양식으로 작성해주세요.
> **게임 이름**과 **버그 내용**만 적으면 됩니다.

---

## 🎯 미니멀 양식 (필수만)

```
[제목] [Varo 후기] ○○ - 번역 막힘

Varo로 ○○ 번역해봤는데 이 부분에서 막혔습니다.

(여기에 어떤 버그/문제가 있는지 한두 줄)

같은 게임 번역해보신 분 있나요?
디버깅용 파일은 채널 룰대로 첨부합니다.

#Varo #게임번역
```

---

## 📋 권장 양식 (디버깅 효율 ↑)

```
[제목] [Varo 후기] ○○ - △△ 부분 번역 안 됨

안녕하세요, Varo 써서 ○○ 번역 시도해봤습니다.

📌 게임 정보
- 게임: ○○
- 엔진: (모르면 비워도 됩니다)

🐛 발생한 문제
- (어디서 막혔는지)
- (어떤 증상인지)

🔧 시도해본 것
- AI: (Claude / Gemini / GPT 등 사용한 거)
- 추출/번역/적용 중 어디서 막혔는지

같은 게임 해보신 분 정보 있으면 댓글 부탁드립니다.
디버깅 도와주실 분이나 Varo 운영자분 보시면
파일은 채널 룰대로 올려뒀습니다.

#Varo #게임번역기 #디버깅
```

---

## 📝 작성 팁

- 게임 이름은 한국어/일본어 둘 다 쓰면 검색 잘 됨
- 모르는 항목은 **그냥 비우거나 "모름"** 적어도 OK
- 게임 파일은 **해당 채널의 국룰대로** 업로드 (운영자가 강제하지 않음)
- 게시물 작성 후 **링크만** Varo 디스코드 #📩문의하기에 공유

---

## 🚫 안 쓰는 게 좋은 표현

| ❌ 이런 표현 | ✅ 대신 |
|------------|---------|
| "○○ 게임 풀버전 공유합니다" | "[Varo 후기] ○○ 번역 막힘" |
| "DLsite ○○ 받아가세요" | "○○ Varo로 시도해봤는데..." |
| "같이 즐겨요" | "같은 게임 번역해보신 분 있나요?" |
| "받았는데 번역 안 됨" | "Varo로 번역 시도했는데 막힘" |

→ **"공유" 톤이 아닌 "번역 시도 후기" 톤**으로 작성

---

## 💡 왜 이렇게 작성하나요?

- 게시물의 주 목적이 **번역 도구 후기/디버깅**임이 명확해짐
- 단순 게임 업로더와 구분됨
- 같은 게임 사용자에게 정보 가치 제공
- Varo 인지도 자연스럽게 올라감
