```
🔄 변경 사항
• 디스코드 서버에 게임 파일 / 다운로드 링크 직접 업로드 금지

• 1인 운영 서비스의 지속가능성 확보
• 디스코드 서버 운영 정책 안정화
• 사용자 본인이 직접 자료를 관리하는 구조로 전환

📋 새 양식 / 작성 예시는 #📋버그리포트가이드 참고

기존에 도움 주신 분들께 감사드리며,
앞으로도 더 안정적인 서비스로 이어가겠습니다.
```

## 📌 안내 (상세 버전)

```
📢 [중요] 서버 운영 정책 변경 안내 (2026-04-29)

안녕하세요, Varo (게임번역기) 운영자입니다.

서비스 안정적인 운영과 1인 운영의 지속가능성을 위해
**게임 파일 공유 방식**을 변경하게 되었습니다.

━━━━━━━━━━━━━━━━━━━

🔄 무엇이 바뀌나요?

[기존]
디스코드 #문의하기에 게임 파일/링크를 base64 인코딩으로 공유

[변경 후]
1. 아카라이브, 코네 등 본인이 자주 이용하시는 인디게임
   커뮤니티에 [Varo 후기] 형식으로 게시물 작성
   (게임 이름 + "이 부분에서 막힘" 한두 줄이면 OK)
2. 디스코드 #문의하기에는 **게시물 링크만** 첨부
3. 양식 / 작성 예시는 #📋버그리포트가이드 참고

━━━━━━━━━━━━━━━━━━━

🤔 왜 변경하나요?

1️⃣ **1인 운영의 지속가능성**
   현재 Varo는 1인 운영 서비스입니다.
   서비스가 오래 가려면 운영 부담을 줄이는 게 필요합니다.

2️⃣ **디스코드 서버 운영 정책 안정화**
   외부 자료가 디스코드 서버에 누적되지 않는 구조로 정비하여
   서버를 가볍고 안정적으로 유지합니다.

3️⃣ **사용자 본인의 자료 관리**
   사용자께서 직접 자료를 보관/공유하시는 방식이
   운영자 의존도가 낮고, 작성한 정보가 오래 남아
   같은 게임을 시도하는 다른 분께도 도움이 됩니다.

━━━━━━━━━━━━━━━━━━━

⏰ 적용 시점

지금부터 즉시 적용됩니다.
이미 공유된 메시지는 점진적으로 정리됩니다.

━━━━━━━━━━━━━━━━━━━

앞으로도 더 안정적이고 좋은 번역 도구로 이어가겠습니다.

— Varo 운영자
```
